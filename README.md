
##1   Design & Styling

- All visual styles come from a single, external stylesheet: **`styles.css`**.
- Colours follow a soft, feminine palette – pinks, roses, and off‑white.
- The layout is **fully responsive** and adjusts for phones, tablets, and desktops.
- No CSS classes were added – the stylesheet targets semantic HTML elements (`header`, `nav`, `section`, `figure`, `blockquote`, etc.).

## 2 Page Descriptions

| Page | Description |
|------|-------------|
| **index.html** | Hero section with call-to-action, highlights of services and products. |
| **about.html** | Salon story, mission, and team introduction. |
| **services.html** | Full list of nail and hair services with prices and photos. |
| **products.html** | Hair and nail products used in the salon (view-only, no online purchase). |
| **gallery.html** | Photo gallery of nail art, hairstyles, and colouring. |
| **testimonials.html** | Real client quotes displayed as blockquotes. |
| **blog.html** | Three sample blog posts with beauty tips. |
| **enquiry.html** | Contact form for booking enquiries (fields: name, email, phone, service, message). |
| **contact.html** | Salon address, phone, email, business hours, and map placeholder. |

## 3 Technologies Used

- **HTML5** (semantic elements, no JavaScript)
- **CSS3** (external stylesheet, responsive design)
